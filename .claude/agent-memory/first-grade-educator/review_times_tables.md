Reviewed rebuilt Times Tables (mystery-picture tiles, Leitner boxes, dots -> count-along -> copy scaffold) on 2026-11-14.

Key findings:
- Tile/"known" (rv) awarded at box 2, reachable in the SAME round a fact is introduced (intro with dots -> one clean recall a few questions later). Short-term memory, not retention. Recommended requiring box 2 only from a later round/day.
- "Count the dots" for 7x8 / 12x12 means counting 56-144 dots one by one: frustration loop for a 6-year-old. Recommended tappable rows showing running totals (child-driven skip count) before the automatic count-along.
- Answers with dots/hint shown counted as first-try right (streak, Dad report accuracy, f.r) - inflates progress reporting.
- Copy stage ghost disappears on first typed digit.
- 11s/12s (3-digit products) are well beyond grade level; suggested capping at 10x10 first.

**Why:** Recurring theme across reviews: "what counts as success" logic tends to be too generous (see [[review-pipeline-game]] always-100% bug).
**How to apply:** In future reviews, always trace exactly when mastery/progress flags are set and whether helped answers count as unaided.
